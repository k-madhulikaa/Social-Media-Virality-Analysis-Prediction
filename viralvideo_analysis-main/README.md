# Video Virality Analysis

This project analyzes video data to understand the factors related to video performance and uses machine learning models to predict video virality.

The project includes data preprocessing, exploratory data analysis, machine learning, model interpretation and an interactive dashboard.

## About the Project

The main objective of this project is to study video-related data and identify patterns that can help understand why some videos perform better than others.

Different machine learning models are used for prediction, and SHAP is used to understand the contribution of different features to the model predictions.

## Dataset

The dataset used for this project is included in the repository.

It is used for:

- Data preprocessing
- Exploratory data analysis
- Feature analysis
- Model training
- Model evaluation

The dataset is processed and analyzed in the project notebook.

## Project Workflow

1. Load and explore the dataset
2. Clean and preprocess the data
3. Perform exploratory data analysis
4. Analyze important features
5. Prepare the data for machine learning
6. Train machine learning models
7. Compare model performance
8. Use SHAP for model interpretation
9. Present the results through an interactive dashboard

## Machine Learning Models

### Random Forest

Random Forest is used to learn the relationship between the input features and video performance.

### XGBoost

XGBoost is used as another prediction model and is compared with the Random Forest model.

### SHAP

SHAP is used to interpret the machine learning models and identify the features that have the most influence on the predictions.

## How to Run

### 1. Clone the Repository

    git clone https://github.com/Pranavi77-lab/viralvideo_analysis.git
    cd viralvideo_analysis/src/frontend

### 2. Install Dependencies

Make sure Node.js is installed, then run:

    npm install

### 3. Start the Frontend

Run:

    npm run dev

The Vite development server will start and display the local URL in the terminal.

Open the URL shown in the terminal in your browser.

### 4. Build the Project

To create a production build, run:

    npm run build

### 5. Type Checking

To check the TypeScript code, run:

    npm run typecheck
